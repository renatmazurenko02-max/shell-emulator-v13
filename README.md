# Эмулятор оболочки. Вариант 13

Практическая работа: эмулятор командной оболочки с графическим интерфейсом.
Текущая реализация: этап 1 из запланированных этапов 1-3.

## Требования и запуск

Windows, Python 3.10 или новее с Tkinter. Сторонние пакеты не требуются.
Сборка не требуется. Из папки проекта:

```powershell
py -3 -m src.main
```

Также можно открыть `run.bat`. Для проверки Tkinter: `py -m tkinter`.

## Реализованные возможности

- Графическое окно с именем VFS в заголовке.
- Ввод команд кнопкой или клавишей Enter, журнал ввода и ответов.
- Разбор аргументов с кавычками и подстановка `$NAME` и `${NAME}`
  из окружения реальной ОС.
- Заглушки `ls [путь]` и `cd [путь]`, показывающие имя и аргументы.
- Команда `exit` без аргументов закрывает окно.
- Сообщения о неизвестной команде, неверных аргументах и кавычках.

На первом этапе имя VFS задано константой `VFS_NAME` в `src/gui.py`:
`demo-vfs.zip`. Архив пока не требуется и не загружается. Выбор источника
через параметры запуска будет добавлен на этапе 2, загрузка на этапе 3.
Файлы и каталоги реальной ОС командами эмулятора не изменяются.

## Правила разбора

Это ограниченный учебный синтаксис, а не полная реализация Bash.
Аргументы сначала разделяются с учётом кавычек, затем в каждом
раскрываются переменные. Значение переменной сохраняется одним аргументом.
Раскрытие действует и для текста, изначально заключённого в одинарные
кавычки. Неопределённая переменная заменяется пустой строкой.
Пустой путь и опции, начинающиеся с `-`, отклоняются.
Для Windows-путей при ручном вводе используйте `/`, например `C:/Users`.
Конвейеры, перенаправления и запуск внешних программ не поддерживаются.
Пустая команда игнорируется.

## Проверка в окне

Введите по очереди:

```text
ls
cd /documents
ls "my documents"
ls $USERPROFILE
ls ${USERPROFILE}
unknown
ls a b
cd -x
ls "unfinished
exit now
exit
```

Первые пять команд показывают ответы заглушек. `$USERPROFILE` раскрывается
в путь из окружения Windows; `$HOME` можно использовать, если эта переменная
задана в ОС. Следующие команды показывают ошибки. Последняя закрывает окно.
Скрипт не проверяет существование пути: `ls` и `cd` пока являются заглушками.

## Автоматические тесты

```powershell
py -3 -m unittest discover -s tests -v
```

Либо откройте `test.bat`. Тесты проверяют движок без открытия окна:
пустой ввод, заглушки, переменные, кавычки, ошибки и завершение.
Работу самого окна следует проверить вручную указанными примерами.

## Структура и функции

| Файл или функция | Назначение |
| --- | --- |
| `src/main.py` | Точка входа |
| `src/gui.py`, `main` | Создание окна и запуск цикла событий |
| `ShellWindow.__init__` | Поле ввода, журнал, кнопка, заголовок |
| `ShellWindow.write` | Добавление текста в журнал |
| `ShellWindow.submit` | Приём команды и показ результата или ошибки |
| `src/shell.py`, `expand_variables` | Подстановка окружения |
| `parse_command` | Разделение ввода на команду и аргументы |
| `Shell.__init__` | Сохранение окружения |
| `Shell.execute` | Проверка и выполнение поддерживаемой команды |
| `validate_path_arguments` | Проверка количества и вида аргументов |
| `Result` | Текст ответа и признак завершения |
| `CommandError` | Ошибка команды |
| `tests/test_shell.py` | Автоматические тесты |
